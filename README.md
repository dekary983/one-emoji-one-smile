This is an entry for make.fun's "One Emoji, One Smile" bounty. It writes one heart hands emoji, 🫶, chosen for a warm, friendly first impression to any stranger. The bounty judges emoji pairwise on warmth.

## Run it

```sh
node main.ts
```

This writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset).
